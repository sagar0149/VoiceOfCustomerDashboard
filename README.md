# 📊 AI-Powered Voice of Customer Dashboard

An intelligent customer feedback analysis system that uses **Natural Language Processing (NLP)** and **Sentiment Analysis** to transform customer reviews into meaningful business insights.

---

## 🚀 Project Overview

Organizations receive thousands of customer reviews every day through e-commerce platforms, surveys, social media, and feedback forms. Manually analyzing this data is difficult and time-consuming.

The **Voice of Customer Dashboard** automatically processes customer reviews, identifies customer sentiment, extracts important keywords, and presents insights through interactive visualizations.

This project demonstrates the practical application of:

* Artificial Intelligence
* Machine Learning
* Natural Language Processing (NLP)
* Data Visualization
* Business Analytics

---

## 🎯 Problem Statement

Businesses often struggle to analyze large volumes of customer feedback effectively.

Challenges include:

* Huge amounts of textual review data
* Manual analysis is time-consuming
* Difficult to identify customer satisfaction trends
* Hidden customer concerns remain unnoticed
* Lack of visual business insights

This project solves these problems by automating customer feedback analysis using AI techniques.

## ✨ Features

### 📁 CSV Upload

Upload customer review datasets directly into the dashboard.

### 😊 Sentiment Analysis

Classifies reviews into:

* Positive
* Negative
* Neutral

### 📊 Interactive Dashboard

Includes:

* Sentiment Distribution Pie Chart
* Sentiment Count Bar Chart
* Rating Distribution Chart
* Sentiment vs Rating Analysis
* Review Length Distribution

### 🔑 Keyword Extraction

Identifies important discussion topics from reviews.

### ☁️ Word Cloud

Visual representation of commonly used customer words.

### 📥 Download Report

Export analyzed review data as CSV.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sagar0149/VoiceOfCustomerDashboard.git
```

Navigate into the project:

```bash
cd VoiceOfCustomerDashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
